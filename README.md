# sai-lineart

Минимальный редактор векторного лайна в духе PaintTool SAI: клик точками,
толщина в каждой точке, острые и скруглённые углы. Для мыши, без пера.

## Запуск

PySide6 уже стоит в системе:

```sh
cd ~/Projects/own/sai
python3 -m sai
```

Либо через uv:

```sh
uv venv --system-site-packages
uv run --no-sync python -m sai
```

## Управление

- `1` Draw: клик ставит скруглённую точку, `Ctrl`+клик — острую. Пока ведёшь мышь,
  линия пересчитывается на лету под курсором. Правый клик или `Enter` завершает линию.
  Острая точка — угол: отрезок от неё до следующей точки идёт прямой линией, а
  скругление начинается уже после этой точки. В гладкой точке касательная общая для
  обоих отрезков, поэтому изломов в гладких точках нет: линия проходит точку и
  только потом закругляется.
- `2` Edit: тянуть точки. Двойной клик по точке переключает острая/скруглённая.
  Клик по самой линии вставляет точку прямо на кривой (ширина интерполируется),
  её сразу можно тянуть. `Delete` / `Backspace` или правый клик по точке удаляет её.
  Правится только активный (выбранный в панели) слой; его точки подсвечиваются, а
  штрих под курсором обводится голубым (как в Recolor).
- `2` Edit, выделение: простой клик по точке ничего не выделяет — он её тащит (если
  точка уже в выделении — тащится всё выделение). Выделение — только `Shift`+клик
  (добавить/убрать точку) или драг по пустому месту рамкой (`Shift` — добавить к
  текущему). Выделенные точки тянутся вместе (один `undo` на жест), `Delete` удаляет их
  все (штрих режется на части), колесо над выделением меняет толщину всех выбранных
  точек. `M` — слить выбранные точки в одну (в центр масс, как Blender `M`): две
  концевые точки одного штриха замыкают его, концы двух штрихов сшивают их в один.
  `Shift+M` / меню Edit — замкнуть штрих, правый клик по выделению — контекстное меню
  (merge / close / delete / deselect), `Esc` — снять выделение.
- `3` Erase: стирает точки под курсором, штрих режется на части.
- `4` Width: тянуть по линии, чтобы менять толщину точек.
- `5` Fill по растровому слою: заливка по видимому лайну. Границы — векторные слои и
  растровые слои выше заливки; растровые слои ниже считаются фоном, поэтому открытая
  область заливается до краёв холста. Если активного растрового слоя нет, он создаётся.
- `5` Fill по векторному слою: слой-владелец фигуры **дублируется**, копия кладётся
  под ним (`Fill N`) и заливается — исходник не меняется. В копии штрих под курсором
  получает `bridge` (прямой мост между конечными точками) и `fill` = текущий цвет/alpha;
  если фигура собрана из нескольких штрихов (концы стыкуются ≤ 10 px), в копии они
  заменяются одним общим штрихом с теми же точками (`width=0`, `closed` или `bridge`).
  У копии свои uid у слоя и штрихов, так что ссылки масок не пересекаются.
- `5` Fill подсвечивает под курсором фигуру, которая будет залита: тинт текущего цвета
  по её пути, считается только геометрия (без растеризации, ~1 мс).
- **Convert Vector to Fill** (`Edit`, контекстное меню): копия активного слоя, края
  замыкаются, толщина 0, внутренность заливается текущим цветом — статичная векторная
  заливка.
- **Scope** (`Shift+S` или кнопка на тулбаре): `layer` — правим/заливаем/маскируем
  только активный слой, `image` — все видимые векторные слои изображения.
- `6` Recolor: клик или протяжка по штриху красит его текущим цветом и альфой.
  Попадание учитывает толщину штриха; один `undo` на весь жест. Штрих под курсором
  подсвечивается голубым гало и превью цвета, опорные точки активного слоя видны
  как в Edit. Перекрашивается только активный слой.
- Edit: колесо над точкой меняет её толщину, в пустом месте — зум.
- Draw/Erase/Width: `Shift`+колесо — толщина кисти, просто колесо — зум.
- `Ctrl`+колесо — зум в любом режиме. Толщина может быть 0.
- Средняя кнопка или `Space` + drag: пан.
- `Alt+[` / `Alt+]` — поворот вида на 90° (вращается камера, ориентация холста и
  экспорт не меняются), `Alt+0` — сброс поворота.

## Цвет, слои, файлы

- Кнопка **color** на тулбаре — палитра с альфой; слайдер **alpha** — прозрачность штриха.
- Слои: `+`/`-`, `dup` (`Ctrl+J` — дубликат выше активного), порядок, видимость,
  opacity, blend normal/multiply. Растровые слои помечаются иконкой.
  Двойной клик по имени или `F2` переименовывает слой.
- **Clip to below** — клиппинг по альфе **предыдущего сиблинга** (слоя или группы
  непосредственно ниже в том же списке): `off`, `inside` (виден только там, где у него
  есть альфа — пересечение) или `outside` (вычитается из верхнего: виден только вне его
  альфы). Комбо в панели слоёв.
- **Галочка видимости** убирает сам слой из картинки, но **не отменяет его роль
  трафарета**: скрытая база клипа продолжает маскировать клипнутые над ней слои
  (`Fill 31` можно скрыть, а `Fill 32` с `clip=outside` по-прежнему будет её обходить).
  Группа с частично скрытыми детьми даёт в рендер только видимое, и её же можно ставить
  базой клипа для слоёв выше.
- Маска клипа считается в разрешении экрана/экспорта (при зуме и `Export PNG` клипнутые
  слои не мылятся), обрезается по содержимому базы и кэшируется до изменения геометрии.
  В SVG клип пишется как `clipPath` (бинарная база) или `mask` (мягкая/градиентная).
- **Выделение**: `Ctrl` — добавить/снять слой, `Shift` — диапазон **от последнего
  обычного клика (якоря) до кликнутого слоя включительно**, в обе стороны и по порядку
  обхода дерева (вложенные группы попадают в диапазон целиком). Активный слой (для
  инструментов) — элемент, по которому кликнули последним.
- **Группы**: `grp` (или `Ctrl+G`) оборачивает **всё выделение** в одну группу на месте
  самого верхнего из выбранных, `ung` (`Ctrl+Shift+G`) растворяет все выбранные группы —
  дети встают на их место. Группа ведёт себя как один слой: свои `visible`, `opacity`,
  `blend`, `clip`; opacity/blend применяются ко всему содержимому целиком. Вложенность
  любая, порядок в дереве = порядок отрисовки. `dup` (`Ctrl+J`), `-`, `^`/`v` работают
  на всё выделение в пределах его родителей.
- **Drag&drop** в панели слоёв: перетаскивание выделения меняет порядок и переносит
  слои между группами. Бросок на группу — внутрь (в конец), между элементами — на
  позицию индикатора, на пустое поле — на верхний уровень. Группу нельзя бросить
  внутрь себя или своего потомка.
- Правый клик по слою — контекстное меню: new / duplicate / rename / delete,
  group / ungroup, перемещение вверх-вниз.
- `Ctrl+T` — режим трансформа слоя: тянуть за грань — масштаб по оси, внутри рамки —
  перемещение, снаружи — поворот вокруг центра. `Shift` при повороте — шаг 15°,
  при масштабе — шаг 0.1. `T` — точные значения (угол, масштаб, сдвиг) в диалоге.
  `Enter` применить, `Esc` отменить. Границы берутся из содержимого слоя.
- `File > Canvas Size...` — размер холста.
- `File > Import PNG as Layer...` — подложка (PNG/JPEG/WebP/BMP) как растровый слой.
- `File > Export PNG...` — масштаб 0.5–8x, фон прозрачный или белый.
- `File > Export SVG...` — векторный экспорт.
- JSON — мастер-файл; растровые слои лежат внутри как PNG base64.

Скругление задаётся только флагом точки. Прямых участков нет: каждая точка,
включая концевые, берёт касательную из окружности через себя и двух соседей,
и сегмент строится как дуга этой окружности. Радиус следует из расстояний
между точками. Острая точка использует хорду, поэтому остаётся углом.
Три точки со smooth-серединой дают полукруг.

## Файлы

- `.json` — мастер-файл, версионирован, обратная совместимость держится на нём.
- PNG — экспорт с прозрачностью/белым фоном и масштабом; для покраски в FireAlpaca.
- SVG — векторный экспорт; переменная ширина выводится сегментами с
  `stroke-linecap="round"`, потому что SVG не умеет ширину на точку.
