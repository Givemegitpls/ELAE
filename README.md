# sai-lineart

Минимальный редактор векторного лайна в духе PaintTool SAI: клик точками,
толщина в каждой точке, острые и скруглённые углы. Для мыши, без пера.

## Запуск

PySide6 уже стоит в системе:

```sh
cd ~/Projects/own/sai
python3 -m sai
```

Либо через uv:

```sh
uv venv --system-site-packages
uv run --no-sync python -m sai
```

## Управление

- `1` Draw: клик ставит скруглённую точку, `Ctrl`+клик — острую. Пока ведёшь мышь,
  линия пересчитывается на лету под курсором. Правый клик или `Enter` завершает линию.
- `2` Edit: тянуть точки. Двойной клик по точке переключает острая/скруглённая.
  Клик по самой линии вставляет точку прямо на кривой (ширина интерполируется),
  её сразу можно тянуть. `Delete` / `Backspace` или правый клик по точке удаляет её.
  Правится только активный (выбранный в панели) слой; его точки подсвечиваются, а
  штрих под курсором обводится голубым (как в Recolor).
- `3` Erase: стирает точки под курсором, штрих режется на части.
- `4` Width: тянуть по линии, чтобы менять толщину точек.
- `5` Fill: заливка по видимому лайну. Границы — векторные слои и растровые слои
  выше заливки; растровые слои ниже считаются фоном, поэтому открытая область
  заливается до краёв холста. Если активный слой векторный, под ним создаётся
  растровый слой `Fill`, туда и льётся цвет с альфой.
- `6` Recolor: клик или протяжка по штриху красит его текущим цветом и альфой.
  Попадание учитывает толщину штриха; один `undo` на весь жест. Штрих под курсором
  подсвечивается голубым гало и превью цвета, опорные точки активного слоя видны
  как в Edit. Перекрашивается только активный слой.
- Edit: колесо над точкой меняет её толщину, в пустом месте — зум.
- Draw/Erase/Width: `Shift`+колесо — толщина кисти, просто колесо — зум.
- `Ctrl`+колесо — зум в любом режиме. Толщина может быть 0.
- Средняя кнопка или `Space` + drag: пан.
- `Alt+[` / `Alt+]` — поворот вида на 90° (вращается камера, ориентация холста и
  экспорт не меняются), `Alt+0` — сброс поворота.

## Цвет, слои, файлы

- Кнопка **color** на тулбаре — палитра с альфой; слайдер **alpha** — прозрачность штриха.
- Слои: `+`/`-`, `dup` (`Ctrl+J` — дубликат выше активного), порядок, видимость,
  opacity, blend normal/multiply. Растровые слои помечаются иконкой.
  Двойной клик по имени или `F2` переименовывает слой.
- **Clip to below** — слой виден только там, где есть альфа у слоя ниже (клиппинг).
- **Mask** — общая PNG-маска (читается альфа): одна и та же маска выбирается в
  списке для любого числа слоёв. **Load mask...** создаёт новую маску из файла,
  **Clear mask** снимает её с активного слоя.
- Правый клик по слою — контекстное меню: new / duplicate / rename / delete,
  перемещение вверх-вниз и **Remove Unused Masks** (чистка масок, на которые
  никто не ссылается).
- `Ctrl+T` — режим трансформа слоя: тянуть за грань — масштаб по оси, внутри рамки —
  перемещение, снаружи — поворот вокруг центра. `Shift` при повороте — шаг 15°,
  при масштабе — шаг 0.1. `T` — точные значения (угол, масштаб, сдвиг) в диалоге.
  `Enter` применить, `Esc` отменить. Границы берутся из содержимого слоя.
- `File > Canvas Size...` — размер холста.
- `File > Import PNG as Layer...` — подложка (PNG/JPEG/WebP/BMP) как растровый слой.
- `File > Export PNG...` — масштаб 0.5–8x, фон прозрачный или белый.
- `File > Export SVG...` — векторный экспорт.
- JSON — мастер-файл; растровые слои лежат внутри как PNG base64.

Скругление задаётся только флагом точки. Прямых участков нет: каждая точка,
включая концевые, берёт касательную из окружности через себя и двух соседей,
и сегмент строится как дуга этой окружности. Радиус следует из расстояний
между точками. Острая точка использует хорду, поэтому остаётся углом.
Три точки со smooth-серединой дают полукруг.

## Файлы

- `.json` — мастер-файл, версионирован, обратная совместимость держится на нём.
- PNG — экспорт с прозрачностью/белым фоном и масштабом; для покраски в FireAlpaca.
- SVG — векторный экспорт; переменная ширина выводится сегментами с
  `stroke-linecap="round"`, потому что SVG не умеет ширину на точку.
